## Instrucciones para clonar y usar el repositorio
Para usar o clonar este repositorio en tu laptop o computadora:
1. Abre tu terminal o consola de comandos.
2. Escribe el comando: git clone https://github.com/tracytrujillo/trujillo-tracy-programacion-1.git
3. Ingresa a la carpeta clonada escribiendo: cd trujillo-tracy-programacion-1
4. Abre la carpeta en tu editor de código (en este caso, Visual Studio Code) para consultar las prácticas y proyectos.
